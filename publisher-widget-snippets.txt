SACAQM PUBLISHER WIDGET TEST SNIPPETS
=====================================

Replace YOUR_DEPLOYED_WIDGET_HOST with the public website where the SACAQM
widget app is hosted. Do not include a trailing slash.

Replace STATION_SLUG_OR_ID with a public Johannesburg station slug or ID.
The station selector widget lets readers choose a different Johannesburg
station. The highest PM2.5 stations widget does not need a station value.

Choose either the IFRAME or JAVASCRIPT snippet for each widget. An iframe is
the simplest test. For JavaScript snippets, add the matching <div> and include
the shared loader script only once on the page. You can put several widget divs
on one page.

These snippets load the hosted widget app. When SACAQM changes the design and
redeploys the app, publisher pages using these snippets receive the new design
without changing their embed code.


1. CURRENT AIR QUALITY
----------------------
Shows current PM2.5, air-quality category, station location and other readings.

IFRAME:
<iframe src="https://YOUR_DEPLOYED_WIDGET_HOST/#/news-widgets?widget=current-aqi&embed=1&theme=light&station=STATION_SLUG_OR_ID" width="100%" height="320" loading="lazy" frameborder="0" title="SACAQM Current Air Quality"></iframe>

JAVASCRIPT:
<div data-sacaqm-widget data-widget="current-aqi" data-station="STATION_SLUG_OR_ID" data-theme="light"></div>

7. HIGHEST PM2.5 STATIONS (ROTATING)
------------------------------------
Ranks Johannesburg stations by their latest PM2.5 readings. It starts with the
highest reading, then randomly rotates through the top five every 12 seconds.
No station value is needed.

IFRAME:
<iframe src="https://YOUR_DEPLOYED_WIDGET_HOST/#/news-widgets?widget=worst-stations&embed=1&theme=light" width="100%" height="500" loading="lazy" frameborder="0" title="SACAQM Highest PM2.5 Stations"></iframe>

JAVASCRIPT:
